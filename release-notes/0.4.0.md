Buffer can now control your fans.

## New
- **Fans:** a Fans page with fan curves: a Simple list, or Advanced with Curves, Wiring and Case views.
- **Fans:** live temperatures and fan speeds.
- **Fans:** import your setup from FanControl.
- **Fans:** find out which fan is which: Buffer spins each one and pairs it for you.
- **Fans:** profiles and share codes.

## Heads-up
- **Fans:** opt-in. Turning it on asks for administrator approval once; it uses LibreHardwareMonitor, which comes with the installer (nothing extra to download).
- **Fans:** fail-safe: if Buffer stops, the fans go back to the board's own settings.
