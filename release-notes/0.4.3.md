Settings and RGB open much faster, and Equalizer APO setup works on PCs with many audio devices.

## Improved
- **Settings:** the Advanced tab opens about six times faster (it no longer waits for the keyboard scan, ffmpeg and the cache size).
- **RGB:** the page opens faster, and its status no longer rescans the keyboard on every refresh.
- **Fans:** the status refreshes without starting a helper process each time.

## Fixed
- **EQ:** setting up Equalizer APO no longer fails with "too many devices to set up in one step" on PCs with many audio devices.
