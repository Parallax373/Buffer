RGB finds devices it missed, other lighting programs can be closed from Buffer, and the EQ page can tell when a driver ignores the EQ.

## New
- **EQ:** a Test EQ button that plays a very quiet tone and checks that the EQ really changes it. Some drivers (for example Focusrite USB Audio) never run Equalizer APO, so the EQ looked on but did nothing; the button now says so. Thanks to @Parallax373.
- **RGB:** a button to close the lighting programs that are in the way (Razer Synapse, SteelSeries GG, iCUE and others), and a separate button to stop them starting with Windows. Closing changes nothing else; the autostart button asks for administrator approval once and can be undone in Task Manager → Startup apps.

## Fixed
- **RGB:** Scan again now really searches for devices again (it restarts OpenRGB). Before, a device that was asleep or busy when OpenRGB started only appeared after restarting the PC. Buffer also looks once more by itself when the first search finds nothing.
- **RGB:** in Advanced, a mouse now has its own model and place on the desk instead of being drawn as a strip.
- **RGB:** in Advanced, the CPU fan faces the front of the case, like the fan of an air cooler; an AIO pump has its own place facing the glass.
